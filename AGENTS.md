# Thesis agent instructions

- Preserve argument, citations, research design and measurements unless explicitly asked to revise them.
- Never invent citations, data or findings. Distinguish confirmed results from expected outcomes.
- Commit or publish changes only when requested.
- Do not add private corporate records or raw logs.

## Project documents

| Document | When to read it |
| --- | --- |
| [Thesis standards](.agents/docs/thesis.md) | Before writing, editing, reviewing or collecting sources for the thesis. |
| [Thesis structure](.agents/docs/architecture.md) | To locate active chapters, related sections, historical drafts and literature. |
| [Glossary](.agents/docs/glossary.md) | Before using or reviewing thesis terminology, including the confirmed study conditions. |
| [Research mapping](.agents/docs/research-mapping.md) | When checking how problems, objectives, research questions, methods and results connect. |
| [Research decisions](.agents/docs/decisions/README.md) | When checking what the researcher has confirmed and why. |

Maintain project standards and confirmed definitions in these documents. Link to them from skills.
