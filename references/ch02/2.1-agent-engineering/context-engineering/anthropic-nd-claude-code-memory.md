## Reading notes

Under “Write effective instructions”, Anthropic states: “Claude treats CLAUDE.md files as context, not enforced configuration”. The documentation explains that specificity, organisation and consistency can affect instruction adherence. It also identifies hooks as a mechanism for blocking actions independently of the model's decisions.

This is practitioner documentation, not an empirical estimate of instruction adherence or evidence of the effectiveness of Trade-Harness. It describes the documentation available on the access date, not necessarily the precise capabilities of the Claude Code release used in the study.
