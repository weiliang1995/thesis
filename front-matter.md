**Project Proposal Report**

**Effectiveness of Trade-Harness Agent Orchestration Workflow in Front-End Development: Delivery Efficiency, Code Quality, and Token Cost**

Student: Kuik Wei Liang

Student ID: GS72320

**Abstract**

The trend of using AI coding assistants is increasing in software development, from code prediction and generation to directly participating in the software development workflow. In front-end development, workflow usually includes requirements formation, task decomposition, implementation, unit and integration testing, and code review. Although most of the AI coding assistants can help to accelerate the implementation phase, but the effort spending on other phases is still remains. However, increase autonomy of AI coding assistant and involve them in multiple phases does not automatically reduce the human effort while ensuring the quality and controlling the budget. To address this issue, the study proposes Trade-Harness, an agent orchestration framework designed to coordinate AI agents through a structured development process, enforce architectural constraints, and manage dependencies across a central monorepo and multiple component repositories. A 12-week quasi-experimental study will be conducted by two front-end developers in a React and TypeScript front-end system. The study covers real production tasks including feature implementation, bug fixing, and code refactoring. Given a product requirements document (PRD), the Trade-Harness workflow proceeds through task decomposition, optional technical requirements document (TRD) generation, agent assignment, code generation, validation, testing, and code review. The study compares a conventional prompt-based workflow, in which developers manually construct prompts and select relevant context, with the structured Trade-Harness workflow. Effectiveness will be evaluated using three categories of metrics: delivery efficiency, measured by delivery lead time from the transition of a Jira issue to In Progress until QA staging; code quality, measured by defect density and integration testing pass rate; and computational cost, measured by lines of code generated per million tokens and token cost per issue. The study is expected to provide empirical insights into the effectiveness of Trade-Harness by the task-complexity levels, and identify a balance that is reasonable and acceptable for an industrial front-end development team.

Keywords: Agent-based software engineering; Agentic workflow orchestration; Software development productivity; Front-end development; Token cost efficiency
