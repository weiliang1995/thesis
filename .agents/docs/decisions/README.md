# Research Decision Records

Record consequential research decisions confirmed by the researcher. Use the [RDR format](../../skills/research-grill/references/rdr-format.md) and name each new file `NNN-short-slug.md` using the next available number. Create records for choices that materially affect the research design or interpretation, have meaningful alternatives or would be difficult to reconstruct from the manuscript. Routine wording changes can be tracked in the manuscript diff.

Record the researcher's approval and identify any separate supervisor approval or empirical evidence explicitly. Keep identifiable participant data out of decision records and follow the [project rules](../../../AGENTS.md) on private records.

Existing decisions can be reconstructed from active manuscript sections and research records, then confirmed with the researcher before recording. Preserve superseded records and link replacements.
