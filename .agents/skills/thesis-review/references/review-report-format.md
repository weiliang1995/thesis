# Review Report Format

## Scope and coverage

- Snapshot: branch and commit (or explicitly uncommitted scope)
- Requested scope / axes / diff base if applicable
- Reviewed files and cross-chapter dependencies; excluded and missing material
- Review execution: isolated subagents or separate non-isolated passes
- Coverage per axis: claims, terms or traceability links inspected; outstanding items and inaccessible sources

## Findings (separate by axis)

For each finding use a stable ID (CE-001, TA-001, AL-001), severity, status, exact manuscript path + heading/line range, short excerpt, supporting or conflicting source + locator, explanation, impact and actionable recommendation. Quote only enough text to identify the issue. Cross-reference overlapping findings; do not collapse axes into a single score.

Severity:
- Critical: threatens the ability to answer an RQ, invalidates a central claim or compromises research integrity.
- Major: materially affects meaning, evidence, comparability, interpretation or reproducibility.
- Minor: localized ambiguity or consistency issue with limited research impact.

Severity is impact, not certainty. Status: Confirmed finding, Needs verification, or Pending material. Never present a suspected issue as established. For evidence use the claim-specific statuses from the axis reference.

## Axis-specific artifacts

- Evidence: claim register or compact coverage summary plus actionable register and explicit unverified claims.
- Terminology: term/definition/usage comparison.
- Alignment: traceability matrix and orphan/broken links.

## Next actions

Distinguish straightforward proposed revisions, source verification, research-grill decisions, research-terminology decisions, and supervisor/data dependencies. No automatic edits. Report zero findings only when the stated scope was actually reviewed; never equate zero findings with verified thesis correctness.
