## 4.5 Computational Resource Efficiency and Cost Results (RQ3)

> **Provisional results (dataset snapshot reviewed 2026-11-22):** 548 Jira issues, ten developers, 302 baseline tasks and 246 Trade-Harness tasks. The final research-sample definition remains open. Findings below are descriptive; tasks were not randomly assigned.

Computational outcomes are measured as **changed production-code LOC per million input/output tokens** and **task-linked LLM gateway cost per issue (USD)**. Gateway totals are available at task level only; planning, implementation and validation costs cannot be separated.

### 4.5.1 Changed LOC per Million Tokens

For each issue with positive token usage, the ratio is `changed production LOC / (input tokens + output tokens) × 1,000,000`. This is a measure of change volume relative to model usage, not functional value or productivity.

**Table 4.9. Task-level changed LOC per million tokens**

| Statistic | Baseline | Trade-Harness |
|---|---:|---:|
| Valid tasks (n) | 301 | 246 |
| Mean | 18.09 | 15.87 |
| Median | 10.29 | 8.06 |
| Standard deviation | 21.37 | 19.79 |
| IQR | 17.47 | 12.94 |
| Range | 0.00–132.57 | 0.69–115.87 |

Trade-Harness has a lower mean (15.87) than the baseline (18.09). Because this measure is sensitive to the type and scope of code changes, it should not be interpreted as evidence that either workflow produces less useful code.

**Table 4.10. Supporting totals, matched-usage issues only**

| Measurement | Baseline | Trade-Harness |
|---|---:|---:|
| Matched issues (n) | 301 | 246 |
| Changed production LOC | 306,399 | 219,975 |
| Input tokens | 20,364,395,458 | 20,220,073,543 |
| Output tokens | 102,012,403 | 107,318,598 |
| Total tokens | 20,466,407,855 | 20,327,392,138 |

One baseline issue (**SBU-1207**) lacks linked gateway records and is excluded from this outcome. A task with zero changed production LOC and positive tokens retains a valid ratio of zero.

### 4.5.2 LLM Cost per Issue

**Table 4.11. Recorded LLM gateway cost (USD per issue)**

| Statistic | Baseline | Trade-Harness |
|---|---:|---:|
| Valid tasks (n) | 301 | 246 |
| Mean | 50.89 | 62.19 |
| Median | 27.11 | 30.67 |
| Standard deviation | 71.29 | 93.98 |
| IQR | 41.43 | 43.21 |
| Range | 1.84–496.68 | 3.26–745.45 |
| Sum of available issue costs (USD) | 15,316.85 | 15,298.81 |

Mean recorded cost is **$50.89** for the baseline and **$62.19** for Trade-Harness, an observed difference of **$11.30 per issue**. The medians are $27.11 and $30.67, respectively. Total costs are shown for traceability but cannot be compared directly because the number of eligible cost records differs between conditions.
