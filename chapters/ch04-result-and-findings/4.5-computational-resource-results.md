## 4.5 Computational Resource Efficiency and Cost Results (RQ3)

Resource efficiency was measured as changed lines of production code per million input and output tokens. Cost was measured as recorded enterprise LLM gateway usage cost per completed eligible issue in US dollars. These measures exclude developer labour and other infrastructure costs. Gateway records do not isolate tokens by planning, implementation, validation, or agent stage.
