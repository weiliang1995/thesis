## 4.5 Computational Resource Efficiency and Cost Results (RQ3)

> **Provisional results:** Based on the current ten-developer, 290-task dataset. Only issues with available, positive gateway token counts contribute to the changed-LOC-per-million-tokens metric; a missing gateway cost is not interpreted as zero.

This section examines (1) changed production-code LOC per million input and output tokens, and (2) recorded LLM gateway cost per completed issue in US dollars. The gateway reports task-linked aggregate usage and charges; it does not separate consumption by planning, code implementation, testing, or internal agent stage. The reported dollar costs exclude developer labour and non-LLM infrastructure.

### 4.5.1 Changed Production LOC per Million Tokens

The issue-level ratio was calculated as `changed production LOC / (input tokens + output tokens) × 1,000,000`. The ratio indicates how much code-change volume accompanied a given amount of model usage and is **not** a measure of functional value or developer productivity.

**Table 4.9. Task-level changed production LOC per million tokens**

| Statistic | Baseline | Trade-Harness |
|---|---:|---:|
| Usable issues (n) | 159 | 130 |
| Mean | 20.53 | 14.46 |
| Median | 9.79 | 8.66 |
| Sample standard deviation | 36.36 | 15.89 |
| Interquartile range | 14.47 | 13.23 |
| Minimum–maximum | 0.00–329.80 | 1.08–93.02 |

The baseline mean was **20.53 changed LOC per million tokens** versus **14.46** for Trade-Harness (-29.5% relative to the baseline). The medians were 9.79 and 8.66, respectively. The baseline distribution was more dispersed (SD 36.36 versus 15.89) and contained a notably higher maximum. These descriptive ratios must be interpreted with differences in scope and the nature of changes in mind.

**Table 4.10. Supporting totals for issues with matched gateway usage**

| Measure | Baseline (n=159) | Trade-Harness (n=130) |
|---|---:|---:|
| Production-code changed LOC | 273,582 | 252,618 |
| Input tokens | 20,600,011,873 | 19,984,457,120 |
| Output tokens | 98,974,666 | 110,356,326 |
| Total tokens recorded | 20,698,986,551 | 20,094,813,457 |

One Trade-Harness issue (**DBU-2499**) has no linked gateway usage or cost record, reducing the valid resource and cost sample to 130 in that workflow. Its code change is not counted in Table 4.10, while it remains eligible for other outcome comparisons. The baseline includes the issue with zero production-code changed LOC; this yields a valid zero ratio when its token denominator is positive, unlike defect density, which is undefined for zero changed LOC. A ratio based on pooled group totals is not substituted for the issue-level distribution.

### 4.5.2 Recorded LLM Token Cost per Completed Issue

**Table 4.11. Task-linked LLM gateway cost by workflow (USD)**

| Statistic | Baseline | Trade-Harness |
|---|---:|---:|
| Usable issues (n) | 159 | 130 |
| Mean | 97.05 | 116.81 |
| Median | 58.23 | 72.41 |
| Sample standard deviation | 111.05 | 141.82 |
| Interquartile range | 77.37 | 78.96 |
| Minimum–maximum | 3.18–672.03 | 4.09–844.24 |
| Total cost over issues with available records (USD) | 15,430.82 | 15,184.87 |

The mean recorded cost per issue was **$97.05** for the baseline and **$116.81** for Trade-Harness, an observed increase of **$19.76 per issue** (20.4%). The median was also higher for Trade-Harness ($72.41 versus $58.23). Total group costs should not be compared without accounting for the differing numbers of issues (159 and 130). Both distributions are right-skewed, as their means exceed their medians; the cost range extends to $844.24 in Trade-Harness and $672.03 in the baseline.
