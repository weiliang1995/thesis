## 4.4 Software Quality Results (RQ2)

Software quality was assessed using each task's **final** E2E pass rate and the number of confirmed Jira-linked defects per 1,000 changed lines of production code. The E2E denominator is the number of applicable cases in the task-specific JSON test-case document; failed, unexecuted, or unresolved cases are not counted as passed.

### 4.4.1 Final E2E Test Pass Rate

For every task with a valid JSON test-case document and final E2E report, the task-level pass rate was calculated as passed applicable cases divided by all applicable cases. The comparison describes **task-level distributions** rather than treating all test cases across tasks as independent, equally representative observations.
