## 4.2 Dataset Overview

> **Provisional results (dataset snapshot reviewed 2026-11-22):** 548 Jira issues, ten developers, 302 baseline tasks and 246 Trade-Harness tasks. The final research-sample definition remains open. Findings below are descriptive; tasks were not randomly assigned.

The current dataset contains **548 distinct Jira issues** from **2026-08-03 through 2026-10-23**, based on development timestamps. The issue is the unit of analysis; each issue is associated with one workflow. The records include 324 feature tasks and 224 enhancements drawn from five business lines.

### 4.2.1 Task Distribution

Tasks were classified before development using estimated effort: simple (at most one working day), medium (more than one and up to four working days) and complex (more than four working days).

**Table 4.1. Tasks by workflow and complexity**

| Complexity | Baseline | Trade-Harness | Total |
|---|---:|---:|---:|
| Simple | 232 | 189 | 421 |
| Medium | 64 | 50 | 114 |
| Complex | 6 | 7 | 13 |
| **Total** | **302** | **246** | **548** |

Simple tasks represent 76.8% of the dataset. Only 13 complex tasks are available (six baseline, seven Trade-Harness). Thus, overall comparisons are heavily influenced by simple tasks, while complex-task comparisons have limited observations.

### 4.2.3 Data Completeness

The worksheet includes 1160 Jira status transitions and records 32 reopened issues. Its lead-time values are measured from the first recorded *In Progress* timestamp to the final recorded *Development Complete* timestamp for each issue, including any rework interval. This operational choice will be confirmed before final submission.

**Table 4.3. Valid issue counts by measure**

| Measure | Baseline valid n | Trade-Harness valid n | Exclusion reason |
|---|---:|---:|---|
| Development lead time | 302 | 246 | All issue timestamps present |
| Final E2E pass rate | 300 | 246 | One missing E2E report in each workflow |
| Task-level defect density | 301 | 246 | One baseline issue has zero changed production LOC |
| Changed LOC / million tokens | 301 | 246 | One baseline issue has no linked gateway usage |
| LLM cost / issue | 301 | 246 | One baseline issue has no linked gateway cost |
| E2E test-script correction loops | 300 | 246 | One missing record in each workflow |

Missing reports or gateway usage are not imputed as zero. A task with no changed production LOC has an undefined defect-density ratio but remains eligible for other measures.

**Defect-data note.** The task table currently attributes **634 confirmed defects**, while the separate defect register contains **643 confirmed entries**; nine are flagged in the task table as post-cutoff and are not included in the task-level counts used in this draft. No additional fixed post-completion observation window is imposed. The precise data extraction date must be recorded when finalizing the dataset; a future-dated defect entry also needs verification. These caveats do not change the present calculations, which follow the task table.
