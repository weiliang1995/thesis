### 1.1 Research Background

LLMs are deep learning models trained on large amounts of data that are capable of understanding, interpreting and generating natural language. They are widely used in software engineering to assist developers with coding tasks. Lyu et al. (2025) highlighted the growing popularity of automated programming with the emergence of LLM-based tools such as GitHub Copilot. For example, developers can use GitHub Copilot to provide instructions in natural language and generate code based on these instructions.

However, code implementation is only one part of the software development lifecycle (SDLC). A complete SDLC includes other activities such as requirement analysis, task planning, testing, and code review. Although LLMs can also assist with these tasks, developers still need to plan and organise the steps, provide the necessary context, and validate the outputs generated by LLMs. This dependence of human intervention limits the ability of AI tools to execute multi-step tasks autonomously.

To support more autonomous task execution, approaches such as ReAct have been introduced. ReAct combines reasoning and action in an iterative process, allowing LLMs to interact with external environments and adjust their next actions based on observations (Yao et al., 2023). Despite this autonomy, developers can still supervise agent execution and review the resulting changes through human-in-the-loop approaches (Takerngsaksiri et al., 2025).
