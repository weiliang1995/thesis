#### 4.2.2 Code Quality Metrics

Code quality measures the integration testing pass rate and defect density.

Integration Testing Pass Rate:

$$Pass\ Rate = \frac{N_{passed}}{N_{total}}*100\%$$

where $N_{passed}$ is the number of passing test cases and $N_{total}$ is the total test cases executed in the workflow.

Defect Density: Number of defects introduced by the task that are detected by QA but not caught by AI agent per thousand line of code.
