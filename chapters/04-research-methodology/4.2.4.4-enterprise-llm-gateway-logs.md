##### 4.2.4.4 Enterprise LLM Gateway Logs

LLM usage data originate from the enterprise gateway and are made available with other task metrics in the AI-development analytics dashboard. The confirmed usage fields for this study are input tokens, output tokens, and associated recorded usage cost. Available issue associations are used to aggregate these values for each eligible task.

Total token usage is calculated as recorded input tokens plus recorded output tokens. Token cost per issue is derived from the gateway-recorded cost associated with that issue, expressed in US dollars. The available records do not provide a reliable breakdown of usage by planning, code generation, testing, sub-agent calls, or Trade-Harness workflow stage. Accordingly, the study compares total task-associated usage and cost, without attributing consumption to individual activities. Ambiguous associations and missing usage records are reviewed during data preparation.
