#### 1.1.2 Applications of AI in Front-End Development

Front-end development involves several activities beyond building the user interface. A typical task begins with understanding product requirements and identifying the affected modules. Developers then implement the user interface, manage application state, integrate APIs, and verify whether the changes meet functional and technical requirements. Testing and code review are normally carried out before the changes are delivered for quality assurance.

AI tools can support different stages of this process. For example, design-to-code approaches use multimodal models to generate front-end implementations from interface designs (Si et al., 2025). Coding agents can also help developers inspect existing components, modify application logic, generate tests, and address errors found during validation.

Applying these capabilities consistently can be challenging when a task involves dependencies across several modules or repositories. A change to a shared component, for example, may require corresponding changes to its consumers, type definitions, and integration tests. Producing code for one component is only part of completing the task.

Therefore, the use of AI in front-end development depends not only on its ability to generate or modify code, but also on how the surrounding development activities are coordinated. Agents may be able to perform individual steps, while developers remain responsible for ensuring that the complete task meets the project's requirements and delivery process.
