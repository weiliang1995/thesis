### 1.4 Research Questions

This study compares Trade-Harness with a conventional prompt-based AI-assisted workflow in the selected front-end system, focusing on delivery efficiency, code quality and token cost.

1\. How does the Trade-Harness orchestration framework affect delivery efficiency, specifically regarding delivery lead time, compared to a conventional prompt-based AI-assisted workflow?

2\. How does Trade-Harness affect code quality compared with a conventional prompt-based workflow, based on defect density and integration testing pass rate?

3\. How does Trade-Harness affect computational cost compared with a conventional prompt-based workflow, using lines of code per million tokens and token cost per resolved issue as indicators?
