#### 1.1.1 Agentic AI in Software Engineering

A coding agents can use external tools to interact with development environments. Through tool calling, agents can inspect repository file, search for relevant code, modify existing files, and execute commands such as building or testing an application. These capabilities allow agents to perform development activities beyond generating code suggestions.

For example, a software development task usually involves several activities, such as requirement analysis, task planning, code implementation, and testing. In front-end engineering, developers also need to translate user interface prototype into components and integrate backend APIs. Coding agents can assist with these activities by analysing documents such as Product Requirements Documents (PRDs), exploring the codebase and using UI designs as reference for implementation. Depending on the tools available, agents may also generate components, modify application logic, and execute automated tests.

Rather than executing each activity independently, coding agents can use an iterative process to determine their next actions based on the results of previous steps. For example, after modifying a component, an agent can run tests and inspect the resulsts. If a test fails, the agent can analyse the error messages, make further changes, and run the test again. This feedback loop allows agents to adjust their actions during exectuion, although developers may still need to review the changes and intervene when necessary.
