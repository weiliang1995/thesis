#### 1.1.1 Agentic AI in Software Engineering

AI coding assistants were initially used mainly for activities such as code completion, code suggestions, and generating implementations from developer instructions. With the development of agentic capabilities, these tools can now support more activities across the Software Development Life Cycle (SDLC), including requirement analysis, task planning, implementation, testing, and code review (Otoum & Elkhalili, 2026).

Unlike tools that only return code suggestions, coding agents can interact with development environments, inspect repository files, execute commands, and use the results to decide their next actions. This allows developers to delegate a sequence of related activities rather than controlling every individual step. Human-in-the-loop approaches also allow developers to supervise agent execution and review the produced changes (Takerngsaksiri et al., 2025).

Nevertheless, software development is not completed by performing these activities independently. A development task may require information to be passed between planning, implementation, testing, and review. The output of one activity may also need to satisfy constraints established in an earlier stage.

Although coding agents can support these activities, the way they are coordinated remains important. This is particularly relevant when the development process includes project-specific requirements that may not be fully represented in a general coding instruction.
