#### 1.1.1 Agentic AI in Software Engineering

With the capabilities of ReAct mechanism, coding agents can now interact with development environments by tool calling, inspect repository files, execute commands, and use the results to decide their next actions.

For example, in front-end engineering, a Product Requirements Document (PRD) is provided by product manager to start a SDLC, agent can first parse the document, retrieving the information, inject with development environment context, such as codebase, coding standards and linting rule. Then agent will generate a development plan, including task decomposition, implementation steps and validation gate. Nevertheless, agents can also parse the prototype to understand the user interface design of the software. After the implementation is done, agent will executing the unit test and integration test.
