### 1.2 Problem Statement

Although AI coding agents can support various software development activities, challenges remain in managing context, coordinating execution, and maintaining consistent workflows. Agent orchestration provides an approach to organising these activities, but its practical effectiveness in front-end development remains uncertain. Existing studies have examined individual aspects of AI-assisted development, including code generation, context management, agent-based task execution, and resource efficiency. However, there is limited direct evidence comparing structured agent orchestration workflows with conventional developer-managed prompt-based workflows in terms of delivery efficiency, software quality, and computational cost.

This study compares a structured agent orchestration workflow with a conventional prompt-based AI-assisted workflow in a multi-repository front-end development environment. It examines whether the structured workflow leads to differences in delivery efficiency, software quality, and computational cost using data collected from actual development tasks. These concerns are further discussed in Sections 1.2.1 - 1.2.3.
