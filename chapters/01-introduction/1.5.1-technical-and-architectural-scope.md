#### 1.5.1 Technical and Architectural Scope

The selected cryptocurrency trading system is developed using React 18 and TypeScript 5.4. The system consists of a main repository and multiple component libraries. The main repository primarily contains the business logic, main user interface, and state management. The component libraries contain the code for various components, which are published and managed in a private package registry.

In daily front-end development, a feature change requires adjustments to business logic, page state, and user interface in the main repository, and may also involve shared components, type definitions, or utility functions in the component library. Developers need to confirm the changes between the main repository and the component library, and verify whether the main repository can correctly reference and integrate these changes after the components are released. Therefore, the development process of this system inherently features cross-repository collaboration, reflecting the actual situation of context selection, dependency understanding, and change verification in front-end development.
