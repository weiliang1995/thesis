#### 1.5.2 Definition of the Orchestrated Workflow

In this study, orchestrated workflow refers to Trade-Harness. Instead of allowing developers to arbitrarily write prompts for tasks, it uses documentation provided by the developers and leverages the rules and limitations within layers to select the necessary tools and contexts for each task, and then assigns agents to perform various tasks. The agents also review their output after each task and use feedback for future adjustments.

It is important to note that Trade-Harness does not change the behaviour of the language model itself, and it does not design to replace any developer in the entire software development process. Its role is to organize how the language model is used in the development process, especially providing a more consistent execution structure for in front-end development.
