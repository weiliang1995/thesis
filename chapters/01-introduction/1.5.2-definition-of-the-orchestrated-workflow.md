#### 1.5.2 Definition of the Orchestration Workflow

This study compares two development workflows: a prompt-based workflow and a structured agent orchestration workflow implemented as Trade-Harness. Both workflows use Claude Sonnet 4.6 through Claude Code CLI in the same development environment.

In the prompt-based workflow, developers interact directly with Claude Code through natural language instructions to plan, implement, and validate development tasks. Developers coordinate the overall development process, while Claude Code retains its native agent capabilities, including repository exploration, tool calling, code modification, and testing.

In the structured agent orchestration workflow, Trade-Harness organises development activities through predefined workflow rules. These rules guide task decomposition, context management, execution stages, and validation. Agents can still make decisions and execute tasks within the defined workflow.

The main difference between the two workflows is how agent activities are organised and controlled, rather than the underlying model or its native capabilities. The detailed workflow configurations and execution procedures are described in Chapter 3.
