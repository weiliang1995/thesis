#### 1.2.1 Lack of Workflow Orchestration in AI-Assisted Development

AI coding assistants can assist in the process of writing code, but code generation is only one part of software development activities. Before and after the code is generated, developers need to clarify the scope, boundaries and constraints, then validate whether the change aligns with the requirement.

With increasing autonomy of AI agents, developers have to move away from direct code writing toward supervising agent decisions and checking their outputs (Takerngsaksiri et al., 2025). In conventional prompt-based approaches, this supervision is mostly defined by individual practice. Developers decide how detailed the prompt should be, including code context and validation instruction. As a result, the workflow can become inconsistent and heavily dependent on the developer’s experience (Otten et al., 2025).

Without a structured mechanism for task decomposition, context management, task execution and validation, the generated code may be locally correct but still require human review before it can be merged and deployed. It remains unclear whether increasing agent autonomy alone can reduce delivery lead time in real-world front-end development.
