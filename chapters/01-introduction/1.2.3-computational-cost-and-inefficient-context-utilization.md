#### 1.2.3 Computational Cost and Resource Efficiency

AI-assisted development can involve repeated model calls for planning, editing, debugging, and validation. Information such as requirements, code context, or earlier decisions may need to be provided again during later interactions. These activities consume tokens and contribute to the cost of completing a development task.

Reasoning-and-action workflows involve successive model interactions with tools and observations (Yao et al., 2022). In software engineering, additional iterations do not necessarily lead to proportionate progress. Fan et al. (2025) argue that agent effectiveness should also be assessed under resource constraints and draw attention to token accumulation and costly unsuccessful attempts.

Structured orchestration may avoid some redundant context handling through explicit task states and controlled execution. At the same time, decomposition, agent coordination, and validation gates can introduce their own model calls and overhead. The concern is therefore not simply to minimize token consumption, but to compare the resource efficiency and financial cost of the two workflows for completed development tasks. This study uses lines of code per million tokens and token cost per resolved issue for that comparison.
