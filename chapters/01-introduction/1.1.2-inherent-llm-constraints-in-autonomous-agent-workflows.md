#### 1.1.2 Constraints of AI Coding Agents

Although coding agents can access large amounts of information, this does not guarantee that they can identify and use all relevant information correctly. In large-scale software projects, context may be distributed across multiple repositories, modules, documentation, and configuration files. Coding agents can search repositories, read files and retrieve relevant information through tool calling, but they still need to determine which information is relevant to the current task and should be included in the context window. Incomplete and irrelevant context may affect an agent's ability to understand requirements, code dependencies and project constraints.

>Lost in the Middle: How Language Models Use Long Contexts（Liu et al., 2024）

Beyond selecting relevant context, coding agents also face challenges in retaining information across long-running tasks and multiple sessions. As a task progresses, earlier instructions, decisions, and execution results may be compressed or removed to make room for new information. Furthermore, information retained during one session may not be available in subsequent sessions unless an external memory mechanism is used. Therefore, maintaining and retrieving relevant information across different stages and sessions remains a challenge for coding agents.

Furthermore, LLMs produce probabilistic outputs, which can vary even under similar inputs. In software development, the coding agents rely on LLM-generated decisions to plan tasks and select tools, the indeterminism may cause their execution paths to vary. Such variability may lead agents to omit certain development or validation steps, particularly when project-specific requirements are not sufficiently enforced.
