##### 4.2.4.1 Jira Records

Jira provides the feature-development issue records, task identifiers, and status histories used to calculate delivery lead time. For each eligible task, the relevant timestamps are the transitions to *In Progress* and the intermediate *Development Complete* status. The difference between these timestamps represents the developer-owned delivery interval described in Section 4.2.1.

Confirmed defects linked to each feature-development issue are obtained through Jira issue relationships and counted for the defect-density measure. The task's assigned workflow and pre-task complexity category are retained alongside these records for comparison; these research classifications are not assumed to be native Jira fields. Jira-based information is available within the existing AI-development dashboard, with the underlying issue records serving as the source of task and defect information.
